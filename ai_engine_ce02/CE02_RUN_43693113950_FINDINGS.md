### Verification boundary

These observations establish **gaps in tested current interfaces**, not a proof that Nat20-Rust is unadaptable. In particular:

1. G07 does **not** test a seeded API, because this public dice-roll API takes no seed. Results differing without a seed are expected. The useful negative evidence is that raw dice calls cannot be replayed deterministically by a caller merely repeating the inputs.
2. G08 does **not** prove the absence of all possible snapshot/recovery implementations. It proves that the direct `EngineState: Serialize` contract is unavailable at the pinned revision. An alternative checkpoint or event-sourcing strategy is untested.
3. G09 establishes that `Inventory::items()` exposes definition-level identity, not distinct copy identities in the tested case. It does not establish that an external instance ledger is impossible.
